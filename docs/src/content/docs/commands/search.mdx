`grep` follows GNU grep 3.11 and `rg` follows ripgrep 14.1, including options, output format, colors and exit status. Both run in-process and need no installed binary.

---

## grep

Print lines that match patterns, from files or from the pipeline.

```
grep [OPTION]... PATTERNS [FILE]...
grep [OPTION]... -e PATTERNS ... [FILE]...
grep [OPTION]... -f PATTERN_FILE ... [FILE]...
```

`egrep` is `grep -E` and `fgrep` is `grep -F`.

### Two modes

<Tabs>
<TabItem label="Pipeline mode">

When objects are piped in and no file is named, grep matches each object's `BashText` and emits the **original object** on a match.

```powershell
ls -l | grep '.ps1'
```

The output looks like text, but each result is still an `LsEntry`:

```powershell
$result = ls -l | grep '.ps1'
$result[0].Name             # "PsBash.psm1"
$result[0].SizeBytes        # 141234
```

Types survive later stages too:

```powershell
$big = ls -l | grep '.ps1' | sort -k5 -rn | head -n 1
$big.SizeBytes   # still a number
```

</TabItem>
<TabItem label="File mode">

When files are named, or with `-r`, grep reads them and emits one `PsBash.GrepMatch` per output line.

```bash
grep -n 'function' src/PsBash.psm1
```

```text
7:function Get-BashPlatform {
20:function New-BashObject {
```

```powershell
$m = grep -n 'function' src/PsBash.psm1
$m[0].FileName     # "src/PsBash.psm1"
$m[0].LineNumber   # 7
$m[0].Line         # "function Get-BashPlatform {"
```

With several files, or `-r`, each line is prefixed with the file name as you typed it:

```bash
grep -r hi s
```

```text
s/a/x.txt:hi
s/y.txt:hi
```

</TabItem>
</Tabs>

### Flags

Every GNU grep 3.11 option is implemented.

| Flag | Description |
|------|-------------|
| `-E` / `-F` / `-G` / `-P` | Extended regex / fixed strings / basic regex (default) / Perl-compatible regex |
| `-e PAT`, `--regexp=PAT` | Pattern (repeatable) |
| `-f FILE`, `--file=FILE` | Read patterns from FILE (repeatable) |
| `-i`, `-y`, `--ignore-case` / `--no-ignore-case` | Case-insensitive matching / turn it off again |
| `-v`, `--invert-match` | Select non-matching lines |
| `-w` / `-x` | Match whole words / whole lines |
| `-c`, `--count` | Print a count of selected lines per file |
| `-l` / `-L` | List files with / without a match |
| `-o`, `--only-matching` | Print only the matched parts |
| `-q`, `--quiet` | No output; exit 0 on the first match |
| `-s`, `--no-messages` | Suppress messages about missing or unreadable files |
| `-m N`, `--max-count=N` | Stop after N selected lines per file |
| `-n` / `-b` | Prefix line numbers / byte offsets |
| `-H` / `-h` | Always / never prefix file names |
| `-T`, `--initial-tab` | Align output with a tab after the prefix |
| `-Z`, `--null` | NUL after file names |
| `-z`, `--null-data` | Input and output records end in NUL |
| `-A N` / `-B N` / `-C N`, `-NUM` | Context lines after / before / around each match |
| `--group-separator=SEP`, `--no-group-separator` | Separator between context groups (default `--`) |
| `-r` / `-R` | Search directories recursively |
| `--include=GLOB`, `--exclude=GLOB`, `--exclude-dir=GLOB`, `--exclude-from=FILE` | Filter the files searched |
| `-a`, `--text` / `-I` / `--binary-files=TYPE` | Treat binary files as text / as non-matching / `binary`, `text`, `without-match` |
| `-d ACTION` / `-D ACTION` | Directories: `read`, `skip`, `recurse` / devices: `read`, `skip` |
| `--label=LABEL` | Name to show for stdin |
| `--color[=WHEN]` | `always`, `auto`, `never`; colors from `GREP_COLORS` (GNU defaults) |
| `-u` | Accepted, with GNU's obsolescence warning |
| `--line-buffered`, `-U` | Accepted; no effect |

### Behavior

- **Exit status**: 0 when a line is selected, 1 when none is, 2 on an error. An unreadable or missing file makes the status 2 even if another file matched, unless `-q` found a match.
- **Usage errors** exit 2: an unknown or ambiguous option, a bad context length, `grep: conflicting matchers specified` for two of `-E -F -G -P`.
- **Binary files**: a named file with a NUL byte in its first 96 KiB is binary (a file met during a `-r` walk is checked over its first 8 KB). A match prints `grep: NAME: binary file matches` on stderr instead of the line.
- **`-P`**: the pattern is translated to .NET regex, including `\K` at top level, `\Q..\E`, possessive quantifiers, `(?P<n>)`, `\h`, `\R`. Constructs it cannot express (recursion, `(?|`, backtracking verbs, `\K` inside a group) exit 2 with `grep: unsupported PCRE construct`.

<Aside type="note" title="Differences from GNU">
- `grep -r` skips `.git`, `.hg`, `.svn`, `.vs`, `node_modules`, `bin` and `obj` before descending, and skips binary files it meets during the walk without a message. `PSBASH_SEARCH_NO_IGNORE=1` turns the directory pruning off. `-a` searches binary files as text.
- An invalid UTF-8 byte is text, not a binary marker. Only a NUL makes input binary.
- `--color=auto` colors only when ps-bash runs on a terminal (`PSBASH_GREP_TTY=1`/`0` overrides the check).
</Aside>

### GrepMatch Properties

| Property | Type | Description |
|----------|------|-------------|
| `FileName` | string | File name as typed (or the path below a `-r` root) |
| `LineNumber` | int | 1-based line number |
| `Line` | string | The line's text |
| `BashText` | string | The printed line, prefixes included |

`-c`, `-l` and `-L` print plain text records. In pipeline mode the piped objects themselves come out.

### Examples

```bash
grep -i 'error' app.log
grep -E 'warn|error|fatal' server.log
grep -v '^#' config.yml
grep -rn --include='*.sh' 'set -e' .
grep -rl 'Invoke-BashGrep' src/
grep -c TODO *.md
grep -o '[0-9]\+\.[0-9]\+\.[0-9]\+' package.json
grep -B2 -A2 'throw' src/PsBash.psm1
grep -q needle file && echo found
grep -P '(?<=v)\d+' versions.txt
```

```powershell
# Filter typed objects, then use their properties
$logs = ls -l | grep '\.log'
($logs | Measure-Object -Property SizeBytes -Sum).Sum
```

## rg

Recursive search modeled on [ripgrep](https://github.com/BurntSushi/ripgrep) 14.1. With no path, it searches the current directory, or stdin when input is piped in.

```
rg [OPTIONS] PATTERN [PATH...]
rg [OPTIONS] -e PATTERN ... [PATH...]
rg [OPTIONS] --files [PATH...]
```

### Flags

| Flag | Description |
|------|-------------|
| `-i` / `-s` / `-S` | Ignore case / case-sensitive / smart case (the last one wins) |
| `-F`, `--fixed-strings` | Literal pattern |
| `-w` / `-x` | Whole words / whole lines |
| `-v`, `--invert-match` | Non-matching lines |
| `-e PAT` / `-f FILE` | Pattern / patterns from a file (repeatable; makes every operand a path) |
| `-P` | PCRE syntax, translated to .NET regex |
| `-U`, `--multiline`, `--multiline-dotall` | Let matches span lines |
| `-c` / `--count-matches` | Count lines / matches per file |
| `-l` / `--files-without-match` | List files with / without a match |
| `-o`, `--only-matching` | Only the matched parts |
| `-r REPL`, `--replace=REPL` | Replace matches in output (`$1`, `$name`, `${name}`, `$$`) |
| `-q`, `--quiet` | No output; exit 0 on the first match |
| `-m N`, `--max-count=N` | At most N matching lines per file |
| `-n` / `-N` | Show / hide line numbers |
| `--column`, `--vimgrep`, `-b` | Column numbers / `path:line:col:text` / byte offsets |
| `-H` / `-I` | Show / hide file names |
| `--heading` | Group matches under a file-name heading |
| `-A N` / `-B N` / `-C N` | Context lines |
| `--passthru` | Print every line, matches highlighted |
| `--trim` | Strip leading whitespace |
| `-0`, `--null` | NUL after file names |
| `-g GLOB`, `--iglob GLOB` | Include (or `!GLOB` exclude) files by glob |
| `-t TYPE` / `-T TYPE` | Search / skip a file type (ripgrep's 203 built-in types) |
| `--type-list`, `--type-add SPEC`, `--type-clear TYPE` | Inspect or change the type table |
| `--hidden` | Include hidden files and directories |
| `--no-ignore`, `--no-ignore-vcs`, `-u`, `-uu` | Turn off the default pruning (`-uu` also searches hidden files) |
| `-L`, `--follow` | Follow symbolic links and junctions |
| `-d N`, `--max-depth N` | Limit recursion depth |
| `--files` | List the files that would be searched |
| `--sort KEY`, `--sortr KEY` | `path`, `modified`, `accessed`, `created`, `none` |
| `-a`, `--text` | Search binary files |
| `-z`, `--search-zip` | Search inside `.gz` files |
| `-E ENC`, `--encoding ENC` | `utf-8`, `latin1`, `utf-16le`, `utf-16be`, ... |
| `--json`, `--stats` | ripgrep's JSON Lines output / summary statistics |
| `--color WHEN`, `--colors SPEC`, `-p` | Color control; `-p` = color + heading + line numbers |

Refused (exit 2, `recognized but not supported`): `--pre`, `--pre-glob`, `--ignore-file`, `--no-ignore-dot`, `--no-ignore-global`, `--no-ignore-parent`, `--no-ignore-files`, `--no-ignore-exclude`, `--no-ignore-messages`, `--null-data`, `--crlf`, `--engine`, `--max-filesize`, `--max-columns`, `--context-separator`, `--path-separator`, `--one-file-system`, `--debug`, `--trace`. Accepted with no effect: `-j`, `--mmap`, `--no-mmap`, `--line-buffered`, `--block-buffered`, `--no-messages`, `--no-config`.

### Behavior

- **Output layout** follows ripgrep's terminal rules. In a script, or when piped, lines are `path:text` with no line numbers unless `-n`. In an interactive ps-bash terminal, matches are grouped under file headings with line numbers, as ripgrep does on a TTY.
- **Pruning**: hidden entries and the default set (`.git`, `.hg`, `.svn`, `.vs`, `node_modules`, `bin`, `obj`) are skipped before descending. `--hidden`, `--no-ignore`/`-u` or `PSBASH_SEARCH_NO_IGNORE=1` change this. `.gitignore` files are **not** read.
- **Exit status**: 0 on a match, 1 on none, 2 on an error (an unreadable path makes it 2 even when another file matched).
- **Path separators**: a file found below a directory prints with `/` on every platform (`src/a.txt`), as in grep.
- **Argument rules** are ripgrep's: options may follow operands, long options do not abbreviate, and `--color` requires a value.
- **Native ripgrep**: set `PSBASH_RG_NATIVE=1` to hand the command line to a real `rg` on `PATH` (no piped input). Use this when you need `.gitignore` handling, preprocessors or the PCRE2 engine.

### RgMatch Properties

| Property | Type | Description |
|----------|------|-------------|
| `FileName` | string | Path as printed |
| `LineNumber` | int | 1-based line number |
| `Line` | string | The line's text |
| `BashText` | string | The printed line |

Like grep, rg run on piped objects emits the original objects.

### Examples

```bash
rg -n 'function' src
```

```text
src\PsBash.psm1:7:function Get-BashPlatform {
src\PsBash.psm1:20:function New-BashObject {
```

```bash
rg -t sh 'set -e'                     # only shell scripts
rg -g '*.ps1' -g '!*.Tests.ps1' 'Import-Module'
rg -iw 'error'
rg -F '$_.Name'
rg -o '\d+\.\d+\.\d+' package.json
rg -C3 'throw' src/
rg -c 'function' src/
rg -l 'Invoke-Bash'
rg --files -t cs | wc -l
rg 'v(\d+)' -r 'version $1' CHANGELOG.md
rg --hidden 'alias' .
```

### grep vs rg

| | `grep` | `rg` |
|---|--------|------|
| Recursive | With `-r` | By default |
| Hidden files | Searched with `-r` | Skipped unless `--hidden` |
| Pruned directories | `.git`, `node_modules`, `bin`, `obj`, ... | Same set, plus hidden ones |
| File selection | `--include`, `--exclude`, `--exclude-dir` | `-g`, `-t`/`-T` |
| Line numbers in scripts | Off; `-n` turns them on | Off; `-n` turns them on (on in an interactive terminal) |
| Replacement | No | `-r REPL` |
| Pipeline bridge | Passes original objects | Passes original objects |
