`ls`, `find`, `stat`, `tree` and `du` return typed PowerShell objects. The terminal output follows GNU coreutils 9.4 (findutils 4.9 for `find`, tree 2.1 for `tree`), with the differences listed per command, and properties such as `.SizeBytes`, `.Permissions` and `.IsDirectory` stay available to PowerShell.

<Aside type="tip">
Objects survive the pipeline. `ls -l | grep '.ps1' | sort -k5 -n` returns `LsEntry` objects, not strings.
</Aside>

<Aside type="note" title="Paths in output">
On Windows every path these commands print uses forward slashes with the drive letter kept: `C:/Users/you/project`, never `C:\Users\you\project` or `/c/Users/you/project`. Operands may use any of `C:/x`, `C:\x`, `/c/x`, `/mnt/c/x` or a relative path. A name you typed is printed as you typed it (`find src` prints `src/a.txt`). The `FullPath` properties keep the native form for PowerShell callers.
</Aside>

Shared conventions:

- Options parse like GNU getopt: bundles (`-la`), options after operands, unique long-option abbreviations (`--almost` for `--almost-all`), and `--` to end options. Two exceptions: `tree`, like tree(1), does not abbreviate long options, and `basename` matches each option exactly, with no bundles or abbreviations.
- In `ls`, `stat`, `tree`, `du`, and `realpath`, a GNU option that ps-bash does not implement exits 2 with `recognized but not supported`.
- Usage errors use GNU's wording and the `Try 'ls --help' for more information.` hint.

## ls

List directory contents.

### Syntax

```
ls [OPTION]... [FILE]...
```

### Flags

| Flag | Description |
|------|-------------|
| `-l` | Long listing: mode, link count, owner, group, size, date, name |
| `-a`, `--all` | Include names starting with `.`, plus `.` and `..` |
| `-A`, `--almost-all` | Like `-a` without `.` and `..` |
| `-h`, `--human-readable` | Sizes as `4.0K`, `1.2M` (with `-l` or `-s`) |
| `-R`, `--recursive` | List subdirectories recursively, with `dir:` headers |
| `-d`, `--directory` | List directories themselves, not their contents |
| `-1` | One entry per line (the default when output is not a terminal) |
| `-C` / `-x` / `-m` | Columns filled down / across / comma-separated |
| `--format=WORD` | `long`, `verbose`, `commas`, `horizontal`, `across`, `vertical`, `single-column` |
| `-w COLS`, `--width=COLS` | Line length for column formats (else `$COLUMNS`, else 80; `0` = unlimited) |
| `-T COLS`, `--tabsize=COLS` | Tab stops for column alignment (else `$TABSIZE`, default 8) |
| `-S` / `-t` / `-X` / `-U` | Sort by size / time / extension / not at all |
| `--sort=WORD` | `size`, `time`, `extension`, `none` |
| `-r`, `--reverse` | Reverse the sort order |
| `--group-directories-first` | Directories before files |
| `-u` / `-c` / `--time=WORD` | Show and sort by access / change time (`atime`, `ctime`, `birth`, ...) |
| `--full-time` | `-l` with `--time-style=full-iso` |
| `--time-style=STYLE` | `full-iso`, `long-iso`, `iso`, `locale` (default from `$TIME_STYLE`) |
| `-p` / `-F`, `--classify[=WHEN]` | Append `/` to directories / append a type indicator (`/`, `*`, `@`, ...) |
| `-i`, `--inode` | Prefix the inode number (NTFS file index on Windows) |
| `-s`, `--size` | Prefix allocated size in 1 KiB blocks |
| `-n`, `--numeric-uid-gid` | Numeric owner and group (implies `-l`) |
| `-g` / `-o` / `-G`, `--no-group` | Omit owner / omit group / omit group (`-g` and `-o` imply `-l`) |
| `-I PAT`, `--ignore=PAT` | Skip names matching the glob (repeatable) |
| `--hide=PAT` | Like `-I`, but overridden by `-a`/`-A` |
| `-B`, `--ignore-backups` | Skip names ending in `~` |
| `--color[=WHEN]` | `always`, `auto`, `never` |

Refused (exit 2): the quoting options (`-b -q -Q -N --quoting-style --literal ...`), `-f -k -v -D -H -L -Z`, `--block-size`, `--si`, `--dereference*`, `--indicator-style`, `--file-type`, `--hyperlink`, `--dired`, `--zero`, `--context`, `--author`, and `--time-style=+FORMAT`.

### Return type: `PsBash.LsEntry`

One-per-line and `-l` output emit one `LsEntry` per file. Column formats (`-C`, `-x`, `-m`) emit plain text rows, because one row holds several entries.

| Property | Type | Description |
|----------|------|-------------|
| `Name` | string | File or directory name |
| `FullPath` | string | Absolute path (native form) |
| `IsDirectory` | bool | `$true` for directories |
| `IsSymlink` | bool | `$true` for symbolic links and junctions |
| `SizeBytes` | long | Size in bytes (4096 for directories) |
| `Permissions` | string | Mode string, e.g. `-rw-r--r--` |
| `LinkCount` | int | Hard link count |
| `Owner` | string | Owner name |
| `Group` | string | Group name |
| `LastModified` | DateTime | Modification time |
| `AccessTime` | DateTime | Last access time |
| `BirthTime` | DateTime | Creation time |
| `BashText` | string | The formatted line |

### Differences from GNU

- On Windows the mode string is synthesized: 0644 for files, 0755 for directories and executable extensions, write bits cleared for read-only files. A link shows the type letter `l` with the same bits. Owner and group are both the current user name. `-n` prints the last sub-authority of the file's owner SID and primary-group SID.
- `--full-time` prints .NET's 100 ns timestamp resolution (seven digits) followed by `00`.
- `-s` counts whole 4 KiB allocation units.

### Examples

**Long listing:**

```bash
ls -la
```

The listing starts with `total N`, then `.` and `..`. Link-count and size columns are right-aligned to the widest entry in the listing, as in GNU. Files changed in the last six months show `Mon dd HH:MM`; older files show `Mon dd  YYYY`.

**Largest first, human-readable:**

```bash
ls -lSh
```

**Typed properties:**

```powershell
$files = ls -l
$files[0].Name          # "README.md"
$files[0].SizeBytes     # 1084
$files[0].Permissions   # "-rw-r--r--"
```

**Filter and sort without losing objects:**

```powershell
$scripts = ls -l | grep '.ps1' | sort -k5 -n
$scripts[-1].SizeBytes
```

## find

Walk directory trees and evaluate an expression for each entry.

### Syntax

```
find [-H|-L|-P] [-D OPTS] [-Olevel] [PATH...] [EXPRESSION]
```

Words up to the first one that starts with `-`, `(`, `)`, `!` or `,` are start paths (default `.`). The rest is the expression, combined with GNU precedence: `!`/`-not`, then `-a`/`-and` (implicit between terms), then `-o`/`-or`, then `,`. Group terms with `\( ... \)`.

### Tests

| Test | Description |
|------|-------------|
| `-name` / `-iname PAT` | Base name matches the glob (case-insensitive with `-i`) |
| `-path` / `-ipath` / `-wholename` / `-iwholename PAT` | Whole path matches the glob |
| `-regex` / `-iregex RE` | Whole path matches the regex; dialect via `-regextype` (default `emacs`) |
| `-lname` / `-ilname PAT` | Symlink target matches the glob |
| `-type C` | `f`, `d`, `l` (and `b c p s` on Unix), or a list such as `f,d` |
| `-size [+-]N[bcwkMG]` | Size, rounded up to the unit (no suffix = 512-byte blocks) |
| `-empty` | Empty file or directory |
| `-maxdepth N` / `-mindepth N` | Depth limits |
| `-mtime` / `-atime` / `-ctime [+-]N` | Age in days (floor) |
| `-mmin` / `-amin` / `-cmin [+-]N` | Age in minutes |
| `-daystart` | Measure ages from the start of today |
| `-newer F`, `-anewer`, `-cnewer`, `-newerXY REF` | Compare times with a file, or with a date string when Y is `t` |
| `-perm MODE`, `-perm -MODE`, `-perm /MODE` | Mode exactly / all bits / any bit (octal or symbolic) |
| `-user` / `-group` / `-uid` / `-gid`, `-nouser`, `-nogroup` | Ownership |
| `-links N`, `-inum N`, `-samefile F` | Link count, inode, same file |
| `-executable`, `-readable`, `-writable` | Access checks |
| `-true`, `-false` | Constants |

### Actions

| Action | Description |
|--------|-------------|
| `-print` / `-print0` | Print the path with a newline / NUL (the implicit action when none is given) |
| `-printf FMT` | Formatted output: `%p %f %h %P %H %s %m %M %u %g %U %G %y %Y %l %d %n %i %k %b %t %a %c %T* %A* %C* %B*`, with width, precision and `\` escapes |
| `-fprint F`, `-fprint0 F`, `-fprintf F FMT`, `-ls`, `-fls F` | Print to a file / `ls -dils` format |
| `-exec CMD {} ;` / `-exec CMD {} +` | Run a command per match / in batches |
| `-execdir ...`, `-ok ...`, `-okdir ...` | Run from the match's directory / ask first (answer read from stdin) |
| `-delete` | Remove the match (implies `-depth`) |
| `-prune` | Do not descend into a matched directory |
| `-quit` | Stop at the first match |

Options: `-depth`, `-follow`, `-xdev`/`-mount`, `-noleaf`, `-ignore_readdir_race`, `-warn`/`-nowarn` are accepted. `-L`/`-H` follow symbolic links, with GNU's loop detection.

### Return type: `PsBash.FindEntry`

Emitted by the implicit `-print` and by an explicit `-print`. `-print0` and `-printf` emit exact text records instead.

| Property | Type | Description |
|----------|------|-------------|
| `Path` | string | Path as printed (start path as typed, then the path below it) |
| `Name` | string | Base name |
| `FullPath` | string | Absolute path (native form) |
| `IsDirectory` | bool | `$true` for directories |
| `SizeBytes` | long | Size in bytes |
| `Permissions` | string | Mode string |
| `LinkCount` | int | Hard link count |
| `Owner` / `Group` | string | Owner and group names |
| `LastModified` | DateTime | Modification time |
| `BashText` | string | Same as `Path` |

### Behavior

- The walk is lazy and depth-first: each match is printed, run through `-exec` or deleted as it is found, so `find / -name x | head -1` stops early. `-depth` and `-delete` give true post-order.
- Errors match GNU and exit 1: `paths must precede expression`, `` missing argument to `-name' ``, `` unknown predicate `-bogus' ``, `Unknown argument to -type`. A missing start path prints `No such file or directory`, sets status 1, and the remaining paths are still walked.
- Not implemented: `-used`, `-context` (exit 1, `unsupported predicate`).
- On Windows, modes are synthesized as for `ls`, except that links are 0777. Owner and group come from the file's owner SID and primary-group SID. `%D` is the drive letter's character code (`67` for `C:`), ctime is the NTFS change time, and `-newerBt` (birth time) works.

### Examples

```bash
find . -name '*.ps1'
```

```text
./src/PsBash.psm1
./tests/PsBash.Tests.ps1
```

```bash
find . -type f -size +1M                         # larger than 1 MiB
find . -type d -mtime -7                         # directories changed this week
find . \( -name node_modules -o -name .git \) -prune -o -type f -print
find . -name '*.tmp' -delete
find src -name '*.cs' -exec grep -l TODO {} +
find . -type f -printf '%s\t%p\n' | sort -n | tail -n 3
```

```powershell
$big = find . -type f -size +100k
$big | ForEach-Object { "$($_.Name): $($_.SizeBytes) bytes" }
```

## stat

Display file status.

### Syntax

```
stat [OPTION]... FILE...
```

### Flags

| Flag | Argument | Description |
|------|----------|-------------|
| `-c`, `--format` | FORMAT | Print FORMAT with `%` directives, then a newline |
| `--printf` | FORMAT | Like `-c`, but expands `\n`, `\t`, `\\` and adds no newline |
| `-t`, `--terse` | -- | One line of space-separated fields |
| `--cached` | MODE | Accepted and validated; no effect |

Refused (exit 2): `-L`/`--dereference`, `-f`/`--file-system`.

### Format directives

| Directive | Value |
|-----------|-------|
| `%n` | File name as typed |
| `%N` | Quoted file name (`'f'`) |
| `%s` | Size in bytes |
| `%a` | Octal mode, e.g. `644` |
| `%A` | Mode string, e.g. `-rw-r--r--` |
| `%F` | File type: `regular file`, `regular empty file`, `directory` |
| `%U` / `%G` | Owner / group name |
| `%u` / `%g` | Always `0` |
| `%i` | Inode number |
| `%b` | Number of 512-byte blocks |
| `%d` | Device number |
| `%h` | Hard link count (always `1` on Windows) |
| `%X` | Access time, epoch seconds |
| `%Y` | Modification time, epoch seconds |
| `%Z` | Modification time, epoch seconds (GNU: change time) |
| `%%` | Literal `%` |

Any other directive is printed literally.

### Return type: `PsBash.StatEntry`

| Property | Type | Description |
|----------|------|-------------|
| `Name` | string | File name |
| `FullPath` | string | Absolute path |
| `IsDirectory` | bool | `$true` for directories |
| `SizeBytes` | long | Size in bytes (4096 for directories) |
| `Permissions` | string | Mode string |
| `OctalPerms` | string | Octal mode, e.g. `0644` |
| `LinkCount` | int | Hard link count |
| `Owner` / `Group` | string | Owner and group names |
| `Inode` | long | Inode number |
| `Blocks` | long | 512-byte blocks |
| `Device` | long | Device number |
| `LastModified` | DateTime | Modification time |
| `MtimeEpoch` | long | Modification time, epoch seconds |
| `AccessTime` | DateTime | Access time |
| `AtimeEpoch` | long | Access time, epoch seconds |
| `BashText` | string | Formatted output |

### Differences from GNU

- The default block has `File`, `Size`, `Device`, `Access` and `Modify` lines only. `Uid`/`Gid` show names without numbers, and the time is printed with 7 fractional digits and a `+hh:mm` offset.
- `%u` and `%g` print `0`, and `%Z` reports the modification time.
- `-t` prints the octal mode and owner/group names where GNU prints the raw mode in hex and numeric ids. Its device-type and change-time fields are `0`.

### Examples

```bash
stat -c '%s %a %A %F %n' README.md
```

```text
1084 644 -rw-r--r-- regular file README.md
```

```bash
stat --printf='%n\t%s\n' README.md src
stat -t README.md
```

```powershell
$info = stat README.md
$info.OctalPerms    # "0644"
$info.MtimeEpoch    # 1743530400
```

## tree

List a directory as an indented tree. Follows tree(1) 2.1, which is not part of coreutils.

### Syntax

```
tree [OPTION]... [DIRECTORY]...
```

### Flags

| Flag | Argument | Description |
|------|----------|-------------|
| `-a` | -- | Include hidden names |
| `-d` | -- | Directories only |
| `-f` | -- | Print the full path of each entry |
| `-L` | N | Descend at most N levels (N must be 1 or more) |
| `-I` | PATTERN | Exclude names matching the glob; repeatable, `\|` separates alternatives |
| `-n` | -- | No color (accepted; output is never colored) |
| `--dirsfirst` | -- | Directories before files |
| `--noreport` | -- | Omit the `N directories, M files` line |

Every directory operand is walked. Long options do not abbreviate. Other tree options (`-C -p -s -h -P -R -l -J -X -H --gitignore --prune --filesfirst ...`) exit 2. An unknown option is a usage error (exit 1). `-L 0` prints `Invalid level, must be greater than 0.` (exit 1).

### Return type: `PsBash.TreeEntry`

| Property | Type | Description |
|----------|------|-------------|
| `Name` | string | Entry name (empty for the summary line) |
| `Path` | string | Path relative to the tree root |
| `Depth` | int | Nesting depth (0 for the root and summary) |
| `IsDirectory` | bool | `$true` for directories |
| `TreePrefix` | string | Box-drawing prefix |
| `BashText` | string | Prefix plus name |

### Examples

```bash
tree src
```

```text
src
├── PsBash.Format.ps1xml
├── PsBash.psd1
└── PsBash.psm1
0 directories, 3 files
```

The summary line follows the last entry with no blank line, and its directory count leaves out the root. tree 2.1 prints a blank line first and counts the root (`1 directory, 3 files` here).

```bash
tree -L 2 -I 'node_modules|bin|obj' .
tree -d --dirsfirst --noreport .
```

```powershell
(tree src | Where-Object { $_.IsDirectory -and $_.Name }).Name
```

## du

Report space used by files and directories.

### Syntax

```
du [OPTION]... [FILE]...
```

### Flags

| Flag | Argument | Description |
|------|----------|-------------|
| `-s`, `--summarize` | -- | One total per operand |
| `-a`, `--all` | -- | Report files too, not only directories |
| `-c`, `--total` | -- | Add a grand `total` line |
| `-d`, `--max-depth` | N | Report only N levels deep (`-1` = unlimited) |
| `-h`, `--human-readable` | -- | `4.0K`, `1.2M` |
| `-k` / `-m` / `-b`, `--bytes` | -- | Units: KiB (default) / MiB / bytes; the last of `-h -k -m -b` wins |
| `--exclude` | GLOB | Skip matching files and directories |
| `--apparent-size`, `-l`, `-x` | -- | Accepted; no effect |

`-a` with `-s`, and `-s` with a non-zero `-d`, are GNU usage errors. Refused (exit 2): `-B`/`--block-size`, `-D -H -L -P -S -t -X -0`, `--threshold`, `--exclude-from`, `--files0-from`, `--inodes`, `--si`, `--time`, `--time-style`.

### Return type: `PsBash.DuEntry`

| Property | Type | Description |
|----------|------|-------------|
| `Size` | long | Size in the selected unit |
| `SizeBytes` | long | Size in bytes |
| `SizeHuman` | string | Human-readable size |
| `Path` | string | Path as printed |
| `Depth` | int | Depth below the operand |
| `IsTotal` | bool | `$true` for the `-c` total line |
| `BashText` | string | `size<TAB>path` |

### Differences from GNU

Sizes are apparent sizes (the byte length of each file), not allocated blocks, so `du` and `du --apparent-size` print the same figures.

### Examples

```bash
du -sh .
du -h -c -d 1 .
du -d 1 . | sort -rn | head -n 5
```

```powershell
$usage = du -a src
($usage | Measure-Object -Property SizeBytes -Sum).Sum
```

## pwd

Print the current working directory.

### Syntax

```
pwd [-P]
```

### Flags

| Flag | Description |
|------|-------------|
| `-P` | Print the physical name: every symbolic link in the path is resolved |

Without `-P`, pwd prints the logical path: the location as `cd` reached it, links not resolved. The output is the shell form of the path (`C:/Users/you/project` on Windows) and matches `$PWD`. `pwd -P` gives the same name as `realpath .` and `readlink -f .`. The output object is a `PsBash.PwdLine` with a `BashText` property.

### Examples

```bash
pwd
```

```text
C:/Users/you/work/project
```

```bash
cd link-to-project && pwd && pwd -P
```

```text
C:/Users/you/work/link-to-project
C:/Users/you/work/project
```

## basename

Strip the directory and an optional suffix from names.

### Syntax

```
basename NAME [SUFFIX]
basename OPTION... NAME...
```

### Flags

| Flag | Argument | Description |
|------|----------|-------------|
| `-a`, `--multiple` | -- | Every operand is a NAME |
| `-s`, `--suffix` | SUFFIX | Remove a trailing SUFFIX; implies `-a` |

Without `-a`, a second operand is the SUFFIX and a third is an `extra operand` error. A suffix is removed only when the name is longer than the suffix. Output is one plain string per name. `-z` is not an option: it is taken as a NAME.

### Examples

```bash
basename /home/you/work/script.sh          # script.sh
basename /x/y.tar.gz .gz                   # y.tar
basename -s .sh /x/a.sh /x/b.sh            # a, b (one per line)
basename -a a/b c/d                        # b, d
```

## dirname

Strip the last component from each name.

### Syntax

```
dirname NAME...
```

Every argument is a NAME: there are no options. A name with no `/` gives `.`; `/usr` gives `/`. Trailing slashes are ignored. Output is one plain string per name. Backslashes in a Windows path are printed as `/`.

### Differences from GNU

- No `-z`/`--zero`.
- With no operand, `dirname` prints nothing and exits 0. GNU prints `dirname: missing operand` and exits 1.

### Examples

```bash
dirname /home/you/work/script.sh   # /home/you/work
dirname script.sh                  # .
dirname /usr                       # /
cd "$(dirname "$0")"
```

## readlink

Print a symbolic link's target, or a canonical file name.

### Syntax

```
readlink [OPTION]... FILE...
```

### Flags

| Flag | Description |
|------|-------------|
| `-f`, `--canonicalize` | Canonical name with every link followed; all but the last component must exist |
| `-e`, `--canonicalize-existing` | Like `-f`, but every component must exist |
| `-m`, `--canonicalize-missing` | Like `-f`, but no component needs to exist |
| `-n`, `--no-newline` | No newline after the name (ignored, with a warning, for several FILEs) |
| `-q`, `--quiet` / `-s`, `--silent` | Suppress error messages (the default) |
| `-v`, `--verbose` | Report errors |
| `-z`, `--zero` | End each name with NUL |

The last of `-f`/`-e`/`-m` wins, and the last of `-q`/`-s`/`-v` wins.

### Behavior

- Without `-f`/`-e`/`-m`, FILE must be a symbolic link, and its target is printed exactly as stored. Anything else fails silently with status 1. With `-v`, the error is printed: `readlink: d: Invalid argument` for a non-link, `No such file or directory`, or `Not a directory`.
- Canonicalization ports gnulib's `canonicalize_filename_mode`. It walks one component at a time from the root and follows each link where it is met, so `link/..` is the parent of the link's target, not the directory that holds the link. A loop is `Too many levels of symbolic links`.
- The result is printed in shell form (`C:/x/y` on Windows).

### Examples

```bash
ln -s d/f l
readlink l            # d/f
readlink -f l         # C:/Users/you/tmp/d/f
readlink -m new/x     # canonical even though new/ does not exist
readlink -v d         # readlink: d: Invalid argument   (status 1)
```

## realpath

Print the canonical (physical) name of each file.

### Syntax

```
realpath [OPTION]... FILE...
```

### Flags

| Flag | Description |
|------|-------------|
| `-e`, `--canonicalize-existing` | Every component must exist |
| `-m`, `--canonicalize-missing` | No component needs to exist |
| `-P`, `--physical` | Follow each link where it is met (default) |
| `-L`, `--logical` | Fold `..` first, then follow links |
| `-s`, `--strip`, `--no-symlinks` | Do not follow links |
| `-q`, `--quiet` | Suppress error messages |
| `-z`, `--zero` | End each name with NUL |

The default requires all but the last component to exist. The last of `-e`/`-m` wins, and the last of `-L`/`-P`/`-s` wins. `--relative-to` and `--relative-base` exit 2 (not supported).

### Behavior

Uses the same canonicalization as `readlink -f`. With `-s`, a relative operand is made absolute against the physical current directory (the `pwd -P` name). A failure prints `realpath: NAME: reason` (the name GNU-quoted when needed, e.g. `'a b'`) unless `-q` is given, and the exit status is 1. The other operands are still processed.

### Examples

```bash
realpath .                  # C:/Users/you/work/project
realpath -m nosuch/x        # C:/Users/you/work/project/nosuch/x
realpath nosuch/x           # realpath: nosuch/x: No such file or directory  (status 1)
realpath -s link            # the link's own name, not its target
```

## Pipeline Bridge Patterns

Typed objects pass through the pipeline unchanged, so these commands combine with PowerShell.

**Filter `ls` output and read properties:**

```powershell
$large = ls -l | grep '.psm1' | sort -k5 -rn
$large[0].Name
$large[0].SizeBytes
```

**`find` plus `stat`:**

```powershell
find . -name '*.ps1' | ForEach-Object {
    $s = stat $_.FullPath
    [PSCustomObject]@{ Name = $_.Name; Size = $s.SizeBytes; Owner = $s.Owner }
}
```

**Largest entries:**

```bash
du -a . | sort -rn | head -n 10
```
